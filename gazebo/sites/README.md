# gazebo/sites/

Georeferenced Gazebo site worlds, one directory per site, generated by
`gazebo/make_gz_world.py` (ported from DraganflyAircraftEmulator's
`feat/gazebo-site-worlds`). Compose bind-mounts this directory read-only into
the `gazebo` and `autopilot` containers at `/opt/gazebo/sites`.

## Automatic: location in `.env`

Set the site origin in `.env` and start the stack as usual:

```sh
SITE_LAT=-22.380870
SITE_LON=-46.934628
```

```sh
docker compose up -d
```

On every `up`, the one-shot `worldgen` service (`gazebo/worldgen/`):

1. builds `sites/<name>/` with `make_gz_world.py` if it does not exist or its
   inputs (`SITE_*` in `.env`) changed. Otherwise it reuses the site with no
   network access. `SITE_REGENERATE=1` forces a rebuild.
2. writes `sites/.active-<project>`, which holds the world path and the
   site's `sitl_home` (from `site_info.json`).

`gazebo` then loads that world and `autopilot` starts SITL with `--home` on
the world's origin (heading 0, which matches the vehicle spawned facing
north). Both wait for `worldgen` to finish. With `SITE_LAT`/`SITE_LON` empty,
the built-in runway and SITL's default home are used.

`docker compose logs worldgen` shows what was generated or reused. If
generation fails (for example, no network) and an earlier copy of the site
exists, that copy is used with a warning. If no copy exists, `worldgen` exits
with an error and `gazebo` does not start.

## By hand

```sh
pip install -r requirements.txt
python3 gazebo/make_gz_world.py --lat <lat> --lon <lon> --radius 50 --terrain \
    --name <name> --out gazebo/sites/<name>
```

Then either point `.env` at the same location and name (worldgen reuses it
only if the arguments match), or force it with `GZ_WORLD` and `SITL_HOME`:

```sh
GZ_WORLD=/opt/gazebo/sites/<name>/worlds/<name>.sdf
SITL_HOME=<sitl_home from site_info.json>
```

The world must spawn `model://iris_dual_cam` (the script's default
`--vehicle`). That airframe carries the `/cam1` (forward) and `/cam2` (down)
cameras and the FDM port templating. A site's `run.sh` is for running Gazebo
outside this stack; compose ignores it.

## Data sources

The generator downloads Esri World Imagery tiles (check Esri's terms of use),
OpenStreetMap buildings and trees via Overpass (ODbL, attribution required),
Microsoft Global ML Building Footprints (ODbL, a ~30 MB tile cached in the
`worldgen-cache` volume) and OpenTopoData elevation. `--no-osm`,
`--no-ms-buildings`, `--imagery none` and `--elevation` skip them; pass them
through `SITE_EXTRA_ARGS`.
